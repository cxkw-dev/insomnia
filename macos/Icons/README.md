# Provider marks

These transparent marks are tinted to match each provider's quota meters. Their artwork is scaled to a common visual size in the compact dashboard.

- Claude is loaded at runtime from the installed Claude app's `TrayIconTemplate-Dark@3x.png`. It is not bundled here.
- Codex uses the monochrome Codex mark from [Lobe Icons](https://github.com/lobehub/lobe-icons) (`packages/static-png/dark/codex.png`), MIT licensed; see `LOBEHUB-LICENSE.txt`. The installed Codex app only exposes a full app tile, so this transparent rendition avoids a square background.
- Copilot usage in this project comes from GitHub Copilot. Its mark comes from the [Microsoft VS Code Codicons repository](https://github.com/microsoft/vscode-codicons/blob/main/src/icons/copilot.svg) under CC BY 4.0; see `CODICONS-LICENSE.txt`.
